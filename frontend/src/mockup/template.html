    QUICK GUIDE

    화면 연결부터, 선택의 이유까지.

    지금 작성하는 내용은 그대로 두고 이용 흐름을 확인하세요.

    1. 화면 연결

      웹 링크·HTML 파일 또는 Figma·시안을 등록하고, 인식한 화면과 버튼을 확인해요.

    2. 화면 확인

      연결 결과 페이지에서 탐색 진행·페이지·화면 전환을 확인해요. 탐색 완료 또는 확인한 범위 선택 후 다음으로 이동하세요.

    3. 대상 사용자

      제품을 사용할 사람과 사용 상황을 설명하세요.

    4. 참여 구성

      조건과 인원으로 추천받고 필요한 사람을 교체하거나 제외하세요.

    5. 탐색 범위

      사이트 전반을 살펴보거나 특정 흐름을 정하고 핵심 확인 항목을 추가하세요.

    6. 실행

      화면과 선택 인원, 실행 가능 상태를 확인하고 탐색을 시작해요. 화면을 닫아도 서버 실행은 계속됩니다.

    7. 보고서와 인터뷰

      탐색 기록이 쌓이면 문제 지점과 원문을 살펴보고, 기록을 남긴 페르소나에게 질문할 수 있어요.

    8. 수정 회차

      실행한 설정은 보관됩니다. 수정 회차에서 화면을 바꾸고 다시 실행한 뒤, 완료된 회차끼리 비교하세요.

    AI 페르소나의 탐색 기록이며 실제 사용자 조사와 구분합니다.
