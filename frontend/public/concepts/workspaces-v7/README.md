### 확인한 최신 제품 사례

1. [Notion · 2026-02-18 Library 업데이트](https://www.notion.com/releases/2026-02-18): 최근 항목·즐겨찾기·공유 항목 등을 별도 탭으로 모으고 매일 쓰는 항목만 사이드바에 남김. B의 모아보기와 C의 전체/즐겨찾기 탭에 반영.
2. [Linear Changelog](https://linear.app/changelog): 프로젝트 보기와 상태·필터·작업 맥락을 꾸준히 다듬는 실제 제품 사례. 작은 상태 표시와 동일 작업의 보기 전환을 참고. 특정 패턴의 출시일을 새롭게 주장하지 않음.
3. [Dovetail 실제 대시보드 사례](https://www.saasui.design/pattern/dashboard/dovetail): 리서치 자료를 작업 단위로 모아보는 화면 참고.
4. [Vercel 실제 대시보드 사례](https://www.saasui.design/pattern/dashboard/vercel): 프로젝트를 간결하게 정리하는 홈의 참고 경로.

위 자료에서 취한 방향은 가벼운 화면 틀, 상태에만 쓰는 색, 최근 작업과 즐겨찾기, 화면 근거의 미리보기, 상세를 필요할 때 여는 방식입니다. 모든 제품이 동일한 2026 유행을 따른다고 단정하지 않습니다. 제3자 스크린샷과 로고는 데모 자산에 복사하지 않았습니다.

## 가능한 조작

- 네 시안을 상단 링크로 전환. 각 화면에서 보드/갤러리/홈과 목록 전환.
- 이름·설명 검색(Ctrl/Cmd+K), 상태 필터, 웹/모바일 필터, 이름순 정렬.
- 카드 상세, 즐겨찾기, 예시 테스트 생성, 삭제와 되돌리기.
- 페르소나 보관함·실행 기록의 디자인 미리보기.
- 모바일 반응형, 키보드 포커스, 기본 dialog 닫기/Escape, reduced-motion.

## 데이터와 범위

수치·진행률·작업 기록·카드 내용은 자체 작성 예시입니다. 실제 엔진 실행, 실시간 진행, API 호출, 과금, 로그인은 이 시안에서 발생하지 않습니다. 62%는 고정된 시각 예시입니다. 작은 제품 화면은 HTML/CSS로 그린 미리보기입니다. 얼굴은 기존의 AI 이미지 에셋이며 실제 조사 응답자의 사진이 아닙니다.

예시 생성·삭제·즐겨찾기는 personalab-home-v7이라는 별도 localStorage 키만 사용합니다. 실제 테스트 데이터나 로그인 상태에는 영향을 주지 않습니다. 같은 브라우저의 네 시안은 같은 예시 목록을 공유합니다. 개발자 도구에서 해당 키를 지우면 기본 예시로 돌아갑니다.

실제 랜딩·워크스페이스 소스·백엔드·DB는 변경하지 않았습니다. 시안 파일은 이 디렉터리에만 저장했습니다.
