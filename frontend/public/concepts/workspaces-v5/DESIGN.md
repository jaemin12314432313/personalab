# Workspace dashboard — 2026-11-05

사용자가 제공한 3개 이미지의 시각적 완성도와 정보 밀도를 기준으로 새 시안을 만든다.
- 첫 이미지: 밝은 캔버스, 정돈된 2열 패널과 안정적인 화면 비율.
- 두 번째 이미지: 선명한 글자 위계, 일정한 패딩, 얇은 구분선, 절제된 인디고 선택 상태.
- 세 번째 이미지: 제품별 프로젝트 카드와 명확한 생성 동작.

큰 감성 문구와 종이 장식 대신 실제 작업을 화면 중심에 둔다. Pretendard는 유지하며, 208px 접을 수 있는 탐색 메뉴, 68px 상단바, 4개 작은 작업 현황, 최근 탐색과 다음 작업의 2열, 프로젝트 카드로 구성한다. 임의의 생산성·증감률·캘린더·가짜 심각도/점수는 추가하지 않는다.

실제 데이터 구조가 아닌 별도 디자인 예시이다. 현재 프로젝트/테스트/실행 예시 객체에서 모든 개수를 계산하며, ../project-workspace/workspace.js의 생성·상세·비교·저장 미리보기를 재사용한다. 기존 default/editorial 디자인과 D1~D4는 유지한다. DB/API/LLM/원본 카드/인증 저장소는 읽거나 변경하지 않는다.

기능: 워크스페이스, 프로젝트 목록, 페르소나, 전체 실행 기록 이동. 검색/즐겨찾기/정렬, 최근 실행 상태 필터, 다음 작업과 개별 실행 상세, 프로젝트/테스트/실행 설정 추가. 좁은 화면에서는 탐색 메뉴를 접어서 연다.

검증: 기본/기존 D/새 dashboard 경로의 동작과 데이터 파생값, 검색·필터·생성·상세·빈 상태·입력 이스케이프·저장소 격리를 확인한다. 브라우저 도구 연결 제한으로 실제 화면 캡처 확인이 불가능하면 이를 명시한다.
