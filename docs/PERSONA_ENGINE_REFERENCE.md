# 페르소나 엔진 종합 설명서 (점수 v0.3.1)

> 한 장씩 만들어지는 AI 페르소나 카드가 **어떤 순서로, 어떤 조건과 특성으로** 만들어지는지 한곳에 정리했다. 코드(`data/persona_engine/src/`)와 코드북에서 직접 확인한 내용이다.
> 표시: ✅ 현재 엔진에 있음 · 🔶 실험용(엔진 미반영) · ⚠️ 주의

---

## 1. 전체 순서

| 단계 | 하는 일 | 쓰는 자료 | 코드 | 상태 |
| --- | --- | --- | --- | --- |
| 1 | 원자료에서 성인(만 19세 이상)만 남긴다. 8,693명 → 8,266명 | 미디어패널 | `donor.py derive_donor` | ✅ |
| 2 | **타깃 조건**에 맞는 응답자만 추려 부분집합을 만든다 (예: 19~29세 대학생 375명) | 미디어패널 | `engine.py _filter` | ✅ |
| 3 | 부분집합 **안에서** 문항 → 점수를 계산한다 | 미디어패널 | `donor.py compute_scores` | ✅ |
| 4 | 점수 → 등급(낮음·중간·높음)으로 바꾼다. 부분집합 안의 가중 백분위 | 미디어패널 | `utils.grade_balanced` | ✅ |
| 5 | **칸별 할당량**을 정한다. 칸 = 성별 × 연령대 × 직업군 × 학력, 응답자 가중 비율 | 미디어패널 | `engine.py allocate` | ✅ |
| 6 | 칸마다 NVIDIA 후보에서 정한 인원만큼 무작위로 뽑는다 (시드 고정) | NVIDIA | `engine.py` 3단계 | ✅ |
| 7 | 뽑힌 인물마다 **6개 조건이 같은 응답자 1명**을 골라 그 사람의 점수·등급·앱 습관을 통째로 복사한다 (핫덱 매칭) | 둘 다 | `engine.py` 4단계 | ✅ |
| 8 | 뽑힌 인물의 서술(성격·취미)을 불러오고, 등급을 카드 문장으로 번역해 카드를 만든다 | NVIDIA + 번역 표 | `cards.py build_card` | ✅ |
| 9 | 자동 품질 점검: 중복, 할당량, 분포, 매칭 수준, 응답자 재사용, 카드 속 숫자 | - | `checks.py` | ✅ |
| 10 | 화면 행동 규칙을 카드에 붙인다 (설계 가설) | 우리가 정함 | 실험 스크립트 | 🔶 |
| 11 | AI가 카드 + 과제 + 현재 화면을 읽고 행동 하나를 고른다 | 카드 | `backend/services/browser.py` | ✅ |
| 12 | 행동과 불편이 기록되고 리포트가 된다 | - | `report.py` | ✅ |

⚠️ 점수·등급은 **타깃 부분집합 안에서** 계산한다. 같은 응답자가 어떤 패널에 들어가느냐에 따라 등급이 달라질 수 있다.

## 3. 조건 사전

### 3-1. 타깃 조건 (패널을 만들 때 입력)

| 조건 | 값 | 설명 |
| --- | --- | --- |
| 나이 | 만 19세 이상, `최소-최대` | 예: 20-39, 60- |
| 성별 | 남, 여 | |
| 직업군 | 사무·관리, 전문·기술, 판매·서비스, 생산·기능, 농림어업, 학생, 무직·기타 | 여러 개 선택 가능 |
| 학력 | 고졸이하, 대졸, 대학원 | |
| 권역 | 수도권, 광역시, 기타 | |
| 혼인 | 미혼, 기혼 | |
| 인원, 시드 | 기본 100명, 시드 42 | 같은 시드면 같은 결과 |

**프리셋 4종** (현재 400명의 패널)

| 이름 | 조건 | donor | NVIDIA 후보 |
| --- | --- | --- | --- |
| 20대 대학생 (`univ`) | 19~29세 · 학생 · 대졸 | 375 | 16,623 |
| 30대 사무·관리 (`30s_office`) | 30~39세 · 사무·관리 | 333 | 37,033 |
| 40대 전체 (`40s_all`) | 40~49세 | 1,266 | 175,647 |
| 60세 이상 (`60plus`) | 60세 이상 | 3,399 | 330,441 |

### 3-2. 매칭 조건 6개 — 두 자료를 같은 말로 맞추는 기준

| 조건 | 값 | NVIDIA에서 만드는 법 | 미디어패널에서 만드는 법 |
| --- | --- | --- | --- |
| 성별 | 남·여 | 남자/여자의 첫 글자 | 성별 코드 |
| 연령대 | 19-21, 22-24, 25-29, 30대, 40대, 50대, 60대, 70+ | 나이를 구간으로 | 만 나이를 같은 구간으로 |
| 직업군 | 위 7개 | 직업 이름을 **키워드 사전**으로 분류. 19~29세·대졸·직업이 "무직"이고 구직자 서술이 아니면 학생(추정) | 직업코드 구간으로 분류. **재학·휴학 중인 대학·대학원생은 학생** |
| 학력 | 고졸이하, 대졸(전문대+4년제), 대학원 | 학력 문자열 | 최종학력 코드 |
| 권역 | 수도권(서울·경기·인천), 광역시(부산·대구·광주·대전·울산), 기타 | 시·도 이름 앞 두 글자 | 지역 코드 |
| 혼인 | 미혼, 기혼(사별·이혼 포함) | 혼인 상태 | 혼인 코드 |

### 3-3. 할당 칸 (몇 명을 뽑을지 정하는 단위)
성별 × 연령대 × 직업군 × 학력 **4개 조건**의 조합 한 칸마다, 부분집합의 **응답자 가중 비율**대로 인원을 나눈다. 비율은 응답자의 설문 가중치를 합해서 구한다.

### 3-4. 매칭 수준 (얼마나 비슷한 응답자를 찾았나)

| 수준 | 같아야 하는 조건 | 쓰이는 때 | 현재 400명 |
| --- | --- | --- | --- |
| 1 | 6개 모두 | 후보가 5명 이상 | 360명 (90.0%) |
| 2 | 혼인 제외 5개 | 1단계 후보가 5명 미만 | 23명 |
| 3 | 혼인·권역 제외 4개 | 2단계도 미만 | 16명 |
| 4 | 성별·연령대·직업군 3개 | 마지막 | 1명 |

설계서 기준: 3단계 이상이 절반을 넘으면 리포트에 경고. 현재 3단계 이상은 17명(4.25%).

### 3-5. 응답자 재사용
같은 응답자는 한 패널에서 **최대 2번**까지만 쓴다(후보가 모자라면 예외, 현재 초과 0). 400명에 쓴 고유 응답자는 351명이다.

### 4-2. 문항 상세 (실제 코드북 표현)

**학습 용이성** (척도 1 전혀 그렇지 않다 ~ 5 매우 그렇다)
- `m01019` 나는 새로운 디지털 미디어 제품/서비스 사용에 쉽게 익숙해지는 편이다
- `m01020` 새로운 디지털 미디어 제품/서비스의 이용 방법을 배우는 것은 내게는 쉬운 일이다

**정보 검증 성향** (1 전혀 하지 않는다 ~ 5 항상 그렇게 한다)
- `n01038` 내가 접한 정보가 사실인지 아닌지 살펴본다
- `n01041` 타당한 근거를 제시하고 있는지 살펴본다
- `n01042` 상업적 의도를 담고 있는지 판단해본다
- `n01043` 정치적 의도를 담고 있는지 판단해본다
- `n01047` 다양한 입장들을 알아보기 위해 추가정보를 찾아본다

**개인정보 우려** (1~5, 8 = 온라인 활동 안 함 → 결측 처리 후 부분집합 가중 중앙값으로 채움)
- `d23003` 온라인 사이트에 가입할 때 개인 정보를 너무 많이 요구하는 것이 걱정스럽다
- `d23005` 일반적으로 인터넷을 사용할 때 나의 프라이버시에 대해 걱정스럽다
- `d23006` 온라인에서 자기가 누구인지 밝히지 않은 사람들은 의심스럽다
- `d23007` 온라인상에 내가 기억하지 못하는 나에 관한 정보가 삭제되지 않은 채 남아있을까 걱정스럽다
- `d23008` 온라인에서 내 사진 이름 등 개인정보가 도용당할까봐 걱정스럽다

**온라인 거래 익숙함** (5개 요소를 각각 0~1로 환산)
- `i01033` 국내 온라인 쇼핑몰 연간 이용 횟수 (1: 3회 미만 ~ 8: 50회 이상)
- `i02004` 모바일 간편 결제 서비스 사용 여부 (있다 = 1)
- `i02001` 인터넷 전용 은행 사용 여부 (있다 = 1)
- `d25073` 쇼핑 및 공연 등 예약/예매 가능 정도 (1~5)
- `d25072` 모바일 뱅킹 등 금융거래 가능 정도 (1~5)

**생성형 AI 친숙도**
- `d31001` 인지 정도 (1 전혀 모른다 / 2 들어본 적은 있다 / 3 아는 편이다 / 4 잘 알고 있다)
- `d31002` 이용 여부 → 이용이면 "이용", 아니면 인지 정도에 따라 앎(3·4) / 들어봄(2) / 모름(1)

**디지털 활용 능력** (1 전혀 그렇지 않다 ~ 5 매우 그렇다, "가능 정도" 14문항)
문자 발신, 메신저 발신, 메신저 사진·문서 전송, 무선 네트워크 설정, 검색엔진 정보검색, 모바일 뱅킹, 쇼핑·공연 예약, 이메일 열람, 이메일 발송, 환경설정(디스플레이·소리·보안·알람·입력방법), 파일을 컴퓨터로 이동, 앱 설치·삭제·업데이트, 문서·자료 작성, 스팸·피싱 문자 구분 및 차단

**도움 가용성**
- `m01023` 새로운 디지털 미디어 제품/서비스 사용 문제에 대해 도움을 줄 수 있는 특정인(또는 그룹)이 있다 (1~5)

**자주 쓰는 앱**
- `d01001`~`d01003` 자주 이용하는 스마트 기기 애플리케이션 1~3순위 (도서·웹툰, 교육, 게임, 금융, 쇼핑, 지도·내비게이션, 뉴스, SNS, 메신저, 여행, 도구, 음악, 동영상·OTT, 사진, 포털, 배달, 모빌리티, 부동산, 화상통화, 생활정보, 건강관리)

**새것 선호** (소비자 혁신성 16문항, 1~5)
- `m01001`~`m01016` 예: "현재 사용하는 제품에 없는 새로운 기능이 추가된 신제품이 나오면 바로 구매하는 편이다"

### 4-3. 카드에 쓰는 문장 (등급별 번역)

| 특성 | 낮음 / 1 | 중간 / 3 | 높음 / 5 |
| --- | --- | --- | --- |
| 학습 용이성 | 낯선 화면이 나오면 어디를 눌러야 할지 자주 망설인다. | 새 앱은 익숙한 화면이면 바로 쓰고, 낯선 화면에서는 한두 번 헤맨 뒤 익힌다. | 새 앱에 금방 익숙해지고 사용법을 따로 찾아보지 않는다. |
| 정보 검증 | 화면에 나온 안내와 문구를 그대로 믿는다. | 안내 문구는 믿고 따르지만, 결제나 개인정보 같은 중요한 내용은 한 번 더 확인한다. | 처음 보는 서비스는 출처와 근거를 확인하고, 광고처럼 보이는 문구는 의심한다. |
| 온라인 거래 | 온라인으로 결제하거나 예약하는 일이 드물어, 절차가 길면 부담스러워한다. | 온라인 쇼핑과 예약은 해 봤지만, 처음 보는 절차는 천천히 확인한다. | 온라인 쇼핑 · 예약 · 간편결제가 익숙해 가입과 결제 절차를 빠르게 넘긴다. |
| 도움 가용성 | 화면에서 막혀도 도와줄 사람이 마땅치 않아 혼자 해결해야 한다. | 화면에서 막히면 직접 찾아보거나 주변에 물어보기도 한다. | 화면에서 막히면 주변에 물어볼 사람이 있다. |
| 개인정보 우려 | (1~2점) 가입할 때 개인정보를 입력하는 것에 크게 신경 쓰지 않는다. | (3점) 가입 때 개인정보 입력은 보통 넘긴다. (4점) 가입 때 묻는 개인정보가 많으면 불편하다. | (5점) 가입할 때 개인정보를 많이 물으면 걱정이 크고, 이유가 보이지 않는 항목은 특히 불안하다. |
| 디지털 활용 | 스마트폰 설정을 바꾸거나 앱을 설치하는 일은 혼자 하기 어려워한다. | 스마트폰으로 자주 하는 일은 하지만, 설정을 바꾸는 일은 서툴다. | (충분: 문장 없음) |
| 생성형 AI | 이용: 직접 써 봤다 / 앎: 알지만 안 써 봤다 / 들어봄: 들어 봤지만 잘 모른다 / 모름: 잘 모른다 | | |
| 새것 선호 | (문장 없음) | (문장 없음) | 새로운 서비스가 나오면 먼저 깔아보는 편이다. |
| 자주 쓰는 앱 | 평소 ○○·○○ 앱을 주로 써서, 그 앱들의 화면 방식에 익숙하다. | | |

**모순돼 보이는 조합을 한 문장으로 잇는 규칙 (v0.3.1)**

| 조합 | 처리 |
| --- | --- |
| 학습 용이성 낮음 + 디지털 활용 충분 / 새것 선호 높음 | "스마트폰 조작은 익숙하고 새로운 서비스는 먼저 설치해 보지만, 낯선 화면에서는 어디를 눌러야 할지 자주 망설인다." 로 한 문장 |
| 학습 용이성 낮음 + 온라인 거래 높음 | "익숙한 온라인 쇼핑 · 예약 · 간편결제 절차는 빠르게 넘긴다." (범위를 좁힘) |

## 5. 등급이 만들어지는 방식

| 방식 | 해당 특성 | 의미 |
| --- | --- | --- |
| **상대 등급** | 학습 용이성, 정보 검증, 온라인 거래, 도움 가용성, 새것 선호 | 타깃 부분집합 안의 가중 백분위로 낮음·중간·높음. **그 패널 안에서의 위치**라서 패널끼리 절대 수준을 비교하면 안 된다 |
| **절대 등급** | 디지털 활용 능력 | 14문항 평균이 3.0 미만 낮음, 4.0 미만 중간, 그 이상 충분 (젊은 집단에서 만점이 많아 상대 등급이 의미가 없어서) |
| **점수 그대로** | 개인정보 우려 | 1~5 |
| **범주** | 생성형 AI, 자주 쓰는 앱 | |

등급은 동점을 쪼개지 않는 경계로 나누고, 등급별 비율이 **15~50%** 범위를 벗어나면 경고한다.

## 6. 카드 구성

| 줄 | 내용 | 출처 |
| --- | --- | --- |
| 1 | 나이·성별·직업·지역 | NVIDIA |
| 2 | 전공 계열 (대졸 이상일 때) | NVIDIA |
| 3~4 | 성격·취미 서술 (이름 포함) | NVIDIA (합성) |
| 5~ | 학습 용이성 → 디지털 활용(부족할 때) → 온라인 거래 → 정보 검증 → 개인정보 → 생성형 AI → 도움 → 자주 쓰는 앱 → 새것 선호(높고 학습 낮음이 아닐 때) | 미디어패널 → 문장 |
| (실험) | 화면에서의 행동 규칙 블록 | 우리가 정함 🔶 |

카드에 **넣지 않는 것**: 금액·비율 숫자가 든 문장, 건강 서술, 학생 카드의 구직자 서술, 동네 배경 서술(v0.3부터)

## 8. 화면 행동 규칙 🔶 (설계 가설, 효과 실험에서만 사용)

| 특성 | 규칙 | 근거 등급 |
| --- | --- | --- |
| 개인정보 5 | 이유 설명 없이 휴대폰 번호·주소 같은 항목을 요구하면 가입을 그만둔다 | ✗ (혼재) |
| 개인정보 4 | 휴대폰 번호·주소 같은 항목을 요구하면 망설이고, 이유가 보이면 계속한다 | ✗ |
| 학습 용이성 낮음 | 처음 보는 화면에서 무엇을 눌러야 할지 안내가 없으면 두세 번 헤매다 그만둔다 | B |
| 학습 용이성 중간 / 높음 | 안내가 있으면 따라 하고 없으면 한두 번 더 눌러 본다 / 안내 없이 스스로 눌러 보며 익힌다 | B |
| 도움 가용성 낮음 | 막혀도 도움말이나 문의가 보이지 않으면 오래 붙잡지 않고 그만둔다 | B |
| 정보 검증 높음 | 출처가 없는 광고성 문구나 과장된 약속은 믿지 않고 다른 곳에서 확인하려 한다 | C |
| 디지털 활용 낮음 | 인증·설치·설정 단계가 나오면 혼자 하기 어렵다고 느끼고 멈춘다 | B− |
| 온라인 거래 낮음 | 입력·결제·예약 단계가 길어지면 부담을 느끼고 그만둘 수 있다 | B− |

근거 등급과 출처는 [`PERSONA_RULE_EVIDENCE.md`](PERSONA_RULE_EVIDENCE.md)를 본다. 효과 실험 결과는 `PERSONA_EFFECT_EXPERIMENT_2026-11-28.md`(브랜치 `feat/flow-eval-and-concepts`)를 본다.

## 10. 한계와 주의 (종합)

| 구분 | 내용 |
| --- | --- |
| 구조 | **서술(NVIDIA)과 행동 특성(미디어패널)은 서로 다른 사람의 것**이다. 인구통계 조건이 같다는 이유로 이었을 뿐 연결이 보장되지 않는다. 문장만 서로 어긋나지 않게 이었다 |
| 등급 | 상대 등급이라 패널 간 절대 비교가 안 된다 |
| 문항과 문장의 거리 ⚠️ | **새것 선호**는 "신제품을 바로 구매한다" 같은 **소비자 혁신성** 문항인데, 카드는 "새로운 서비스가 나오면 먼저 깔아보는 편이다"로 번역한다. 구매 성향을 설치 행동으로 옮긴 해석이다 |
| 문항과 문장의 거리 ⚠️ | **개인정보 우려**는 5문항 평균인데, 가입 시 개인정보 요구에 관한 문항은 `d23003` 하나이고 나머지는 일반적인 프라이버시 걱정이다. 카드 문장은 "가입할 때"로 좁혀 쓴다 |
| 데이터 | 자기 보고 설문. **막혔을 때 포기하는 행동 문항은 없다.** 포기 기준은 데이터가 아닌 설계 가설 |
| 태도와 행동 | 개인정보 우려가 높은 사람과 낮은 사람의 SNS 계정 공개 설정이 거의 같았다(태도가 행동으로 이어진다는 근거가 약함) |
| 분포 | 40대 패널 2건이 확인 필요 |
| 규칙 | 행동 규칙은 직접 근거(A등급)가 없는 가설. 효과 실험은 "카드 문장이 AI의 행동을 바꾼다"는 것이지 "특성이 실제 사람의 행동을 예측한다"는 증거가 아니다 |
| 합성 | 개인 서술은 LLM이 만든 것이고 실제 사람이 아니다 |
| 규모 | 효과 실험은 사이트 1개, 페르소나 18명 규모 |
