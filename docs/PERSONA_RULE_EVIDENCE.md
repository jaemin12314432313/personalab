# 페르소나 행동 규칙의 근거 점검 (2026-11-28)

> 질문: 카드의 "화면 상황 → 행동" 규칙을 우리가 정해도 되는가, 근거가 있는가?
> 결론: **규칙마다 방향이 맞는 이론·업계 근거는 있지만, "이 특성 수준이면 이 화면에서 그만둔다"를 직접 검증한 근거는 찾지 못했다.** 그래서 규칙은 계속 "설계 가설"로 표시한다. 개인정보 규칙은 오히려 반대 신호가 있다.

## 먼저 바로잡는 해석

효과 실험(`PERSONA_EFFECT_EXPERIMENT_2026-11-28.md`)의 결과 9/18 대 0/18이 보여 주는 것은 **"카드 문장이 AI의 행동을 바꾼다(지시 이행)"** 이다. **"특성이 실제 사람의 행동을 예측한다"는 증거가 아니다.** 우리가 "그만둔다"고 쓰니 그만둔 것이라 순환적이다. 발표·문서에서는 전자로만 쓴다.

## 근거 등급

| 등급 | 뜻 |
| --- | --- |
| A | 특성 → 화면 이탈을 직접 보인 연구 (이번에 찾지 못함) |
| B | 같은 방향의 이론·업계 근거가 있으나 간접적 (맥락·대상·결과 변수가 다름) |
| C | 그럴듯하지만 근거를 찾지 못함 |
| ✗ | 반대되거나 혼재된 근거 |

## 규칙별 점검

| 규칙 (실험에 쓴 문장) | 등급 | 근거 | 한계 |
| --- | --- | --- | --- |
| **개인정보 우려 5** → "이유 설명 없이 휴대폰 번호·주소 같은 항목을 요구하면 가입을 그만둔다" | **✗ (혼재)** | ① 업계: 미국 쇼핑객 중 19%는 신용카드 정보를 믿지 못해, 18~19%는 계정 생성을 원하지 않아 주문을 포기했다고 응답 [Baymard](https://baymard.com/lists/cart-abandonment-rate). ② 학술: 104개 연구 메타분석에서 지각된 프라이버시 위험은 공개 의도와 실제 공개를 모두 낮췄지만 **프라이버시 우려는 의도에만 영향을 주고 실제 행동에는 유의한 영향이 없었다** [Yu 외 2020](https://ideas.repec.org/a/eee/ininma/v51y2020ics026840121831137x.html). 181개 연구 메타분석도 우려가 의도에 더 크게 작용한다고 보고 [Kim 외 2023](https://ideas.repec.org/a/eee/tefoso/v196y2023ics0040162523004742.html). 다만 이 결론의 방법론은 논쟁 중 [Dienlin & Sun](https://open.lnu.se/index.php/metapsychology/article/view/2711). ③ **우리 데이터**: 우려가 높은 사람과 낮은 사람의 SNS 계정 공개 설정이 거의 같음(완전 공개 18% 대 20%) | 업계 수치는 결제 맥락이고 자기 보고. 학술 근거는 "태도(우려)가 행동으로 이어지지 않는다"는 쪽이 우세. **다만 "상황의 위험(이유 없는 민감 정보 요구)"은 행동을 낮춘다는 근거가 있어, 규칙을 특성이 아니라 화면 상황에 걸면 더 방어 가능** |
| **학습 용이성 낮음** → "처음 보는 화면에서 안내가 없으면 두세 번 헤매다 그만둔다" | B | 기술수용모형(TAM)에서 지각된 사용 용이성은 이용 의도의 핵심 결정 요인이다 [개요](https://en.wikipedia.org/wiki/Technology_acceptance_model). 우리가 쓴 두 문항("쉽게 익숙해진다", "배우기 쉽다")이 TAM의 사용 용이성 문항과 의미가 같다 | 효과 크기는 확인하지 못함(검색에서 합산 계수가 안 나옴). 노인 대상 메타분석은 결과가 엇갈린다고 보고 [JMIR 2025](https://www.jmir.org/2025//e65269). TAM은 "도입 의도"이지 "특정 화면 이탈"이 아님 |
| **도움 가용성 낮음** → "막혀도 도움말이나 문의가 안 보이면 오래 붙잡지 않고 그만둔다" | B | UTAUT에서 촉진 조건(지원·자원의 가용성)은 실제 이용을 직접 예측하고, 이용이 자발적이지 않을 때 특히 강하다 [UTAUT 개요](https://open.ncl.ac.uk/theories/2/unified-theory-of-acceptance-and-use-of-technology), Venkatesh 외 2003 (원문은 열람하지 못함) | 촉진 조건은 조직·기술 인프라 지원이고, 화면 안의 도움말 링크와는 다름. 우리 문항은 "주변에 도와줄 사람이 있다" |
| **정보 검증 높음** → "출처 없는 광고성 문구나 과장된 약속은 믿지 않고 다른 곳에서 확인하려 한다" | C | 웹 신뢰도는 사람이 요소를 알아채고(prominence) 해석(interpretation)하는 두 단계로 판단되며 디자인이 영향을 준다 [Fogg, NN/g 정리](https://www.nngroup.com/articles/prominence-interpretation-theory/) | 미디어 리터러시 성향이 높을수록 웹사이트 신뢰 판단이 달라진다는 직접 근거는 찾지 못함 |

## 종합

- 규칙마다 **방향은 이론·업계 근거와 맞는다**(개인정보 규칙의 "특성" 부분만 제외). 그러나 **A등급(특성 → 이탈을 직접 보인 연구)은 하나도 찾지 못했다.**
- 가장 약한 규칙은 **개인정보**다. 학술 근거와 우리 데이터 모두 "우려가 높다고 행동이 달라지지 않는다"는 쪽이다. 단, **화면 상황의 위험**(이유 없는 민감 정보 요구)은 행동을 낮춘다는 근거가 있다.
- 따라서 규칙은 **"설계 가설"로 표시**하고, 근거 등급(B 이하)을 카드·문서에 같이 적는다.

## 권고 (재실험 필요, 아직 반영하지 않음)

1. **표현을 약하게**: "그만둔다" → "그만둘 수 있다". 모든 마찰 큼 페르소나가 확정적으로 이탈하는 것은 근거가 없다. 실험에 쓴 문장은 "그만둔다"였으므로 바꾸면 **같은 실험을 다시 돌려야** 한다.
2. **개인정보 규칙은 특성이 아니라 상황에 건다**: "이유 없이 민감 정보를 요구하면 모든 사람이 불안해한다. 우려가 높으면 더 크게 망설인다" 형태로, 우려 등급은 정도의 차이로만 쓴다.
3. **절대값 대신 순위로 주장**: "마찰 큼이 작음보다 더 자주 그만둔다"까지만. 이는 검증 설계(11장)의 순위 지표 원칙과 같다.
4. **실제 사람으로 보정**: 본 검증(실제 참가자 12~15명)과 앱 리뷰 라벨링으로 규칙의 방향을 확인한다. A등급 근거를 만들 수 있는 유일한 방법이다.

## 이 점검의 한계
- 검색 결과(요약)만 확인했고 논문 원문은 대부분 열람하지 못했다. 효과 크기·세부 조건은 원문 확인이 필요하다.
- 업계 수치(Baymard)는 미국 쇼핑객의 자기 보고이고 표본·기간이 공개 페이지에 명시되지 않았다.
- 한국 사용자·한국 서비스에 대한 직접 근거는 찾지 못했다.
