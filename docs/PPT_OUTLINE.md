## 0. 표지·요약·목차 (3장)

**S01 표지**
- 제목: PersonaLab — AI 페르소나가 먼저 써 보는 UI·UX 탐색과 후속 인터뷰
- 부제: "화면은 같아도, 경험은 다르니까."

**S02 한 장 요약** (다섯 칸)
- 문제: 소규모 팀은 출시 전에 UI·UX를 사람으로 검증할 여력이 없다
- 해결: AI 페르소나 30명이 실제 브라우저로 화면을 직접 쓰고, 막힌 지점을 근거와 함께 남긴다
- 근거: 한국 데이터 기반 페르소나 400명 📏, 자동 테스트 통과 📏, 소규모 실제 실행 확인 🔶
- 시장: 사용성 테스트 소프트웨어 약 4.4억~12억 달러(2025), 연 7~15% 성장 🔎
- 한계: AI 평가가 실제 사람과 얼마나 맞는지는 아직 측정하지 않았다 ⬜

**S03 목차와 읽는 법**

## 1. 문제 정의 (8장)

**S04 배경: 만드는 속도와 검증하는 속도의 격차**
- 프로토타입·웹앱을 만드는 도구는 빨라졌다. Figma만 해도 월간 사용자 1,300만 명 이상이고, 그중 약 2/3가 디자이너가 아닌 사람(개발자·기획자 등)이다 🔎 [Figma 공시 정리](https://sacra.com/research/figma)
- 디자이너가 아닌 사람이 화면을 만드는 비중이 커질수록, UI·UX를 검증해 줄 전문 인력이 없는 팀이 늘어난다

**S05 현재 방식 1: 사용자 테스트의 비용**
- 참여자 1명당 비용 예: Userlytics 약 $49 🔎 [출처](https://getversive.com/help/usertesting-alternatives), UserTesting은 세션당 $34 이상으로 알려짐(미검증) 🔎, Lyssna는 테스트 1분·1명당 약 $1 크레딧 🔎 [출처](https://www.koji.so/blog/lyssna-pricing-2026)
- 50명 기준(스크리닝·녹화 포함) 약 $700 수준이라는 추정 🔎 (같은 출처, 경쟁 업체 블로그라 중립적이지 않음)
- 모집·일정·분석에 걸리는 시간은 숫자로 확인하지 못했다 ⬜

**S06 현재 방식 2: 소수 사용자 테스트의 근거와 한계**
- "5명이면 문제의 약 85%를 찾는다"는 원칙이 널리 쓰인다(각 사용자가 문제를 겪을 확률 31% 가정) 🔎 [MeasuringU 정리](https://measuringu.com/five-users/)
- 그러나 이 수치는 평균적 가정이며, 사용자 숙련도와 문제의 빈도에 따라 달라지고 오용된다는 비판도 있다
- 그래서 "작은 규모를 여러 번 반복"이 권장되지만, 반복마다 모집 비용이 든다

**S07 현재 방식 3: 설문·전문가 평가·지인 피드백**
- 설문은 의향만 묻고 행동을 못 본다 / 전문가 평가는 비싸고 느리다 / 지인 피드백은 편향이 크다
- 표: 방식 × (비용, 속도, 행동 근거, 반복 가능성)

**S08 핵심 문제 정의**
- "소규모 제품팀은 출시 전에 UI·UX를 반복해서 검증할 현실적인 수단이 없다."
- 세부 문제 3개: ① 사람을 모으기 어렵다 ② 결과에 근거(어느 화면, 무슨 행동)가 약하다 ③ 고친 뒤 다시 확인하기 어렵다
- 한국 신규 창업은 2024년 118.3만 개(-4.5%), 2025년 113.6만 개(-4.0%)로 5년 연속 감소 🔎 [아시아경제](https://view.asiae.co.kr/article/2026022516495939459), [경향신문](https://www.khan.co.kr/article/202502281127011). 팀 수가 줄수록 한 팀이 쓸 수 있는 자원은 더 빠듯하다

**S09 우리가 풀지 않는 문제**
- 기획 평가("이 아이디어가 팔릴까"), 사용 의향·기능 선호·지불 의향 조사는 제품 범위에서 뺐다 ✅ ([`CLAUDE.md`](../CLAUDE.md))
- 이유: AI가 말하는 의향과 사람의 행동은 다르다. 우리는 "화면에서 막히는 지점"에 집중한다

**S10 접근: 질문이 아니라 직접 써 보게 한다**
- 질문에 답하는 방식(설문형)이 아니라, 실제 브라우저로 클릭·입력·스크롤하며 막힌 지점을 기록
- 같은 화면 → 다른 페르소나 → 다른 경로와 불편

**S11 연구 질문과 성공 기준**
- RQ1. AI 페르소나의 화면 탐색이 어떤 UI·UX 문제를 근거와 함께 찾아내는가 🔶
- RQ2. 페르소나 특성이 탐색 경로와 발견한 문제의 차이로 이어지는가 🔶
- RQ3. 단일 LLM 호출보다 "페르소나 × 실제 탐색"이 더 구체적인 근거를 주는가 ⬜
- RQ4. 실제 사용자의 이탈 지점과 얼마나 일치하는가 ⬜
- 성공 기준: 정답을 맞히는 도구가 아니라 "어느 화면에서 무엇을 고칠지 근거를 보며 결정하게 하는" 도구 ✅ ([`UX_WORKFLOW.md`](UX_WORKFLOW.md) 1장)

## 2. 타깃 사용자 (5장)

> 팀의 제품 문서가 정한 "주요 사용자"(디자이너·기획자·개발팀·초기 제품팀)를 기준으로, 진입 순서를 아래와 같이 확정한다.

**S12 타깃 한눈에: 진입 순서**
- 1차: 대학 공모전·졸업작품·캡스톤 팀과 사이드 프로젝트 (전문 UX 인력 없음, 비용 민감, 접근 쉬움)
- 2차: 초기 스타트업의 PM·디자이너·개발자 겸임 인력
- 3차: 소규모 에이전시와 프리랜서 디자이너
- 이유: 비용 민감도가 높고 검증 수요가 크며 출시 전 반복 점검이 필요한 순서

**S13 사용자 프로필 1: 졸업작품 팀의 팀장**
- 상황: 4~5명, 시연 2주 전, 사용자 테스트 시간·예산 없음
- 불편: 지인에게 써 보라 해도 "괜찮다"는 답만 돌아옴
- 우리가 주는 가치: 하루 안에 막히는 화면 목록과 근거, 수정 후 2회차 비교

**S14 사용자 프로필 2: 초기 스타트업의 기획자 겸 개발자**
- 상황: 디자이너 없이 직접 화면을 만들어 출시 준비 중
- 불편: 어디가 헷갈리는지 모르고, 출시 후 이탈로 알게 됨
- 가치: 출시 전 반복 점검, 이탈 이유 8개 분류로 우선순위 정함

**S15 사용자 프로필 3: 프리랜서 디자이너·에이전시**
- 상황: 납품 전 클라이언트에게 근거를 보여 줘야 함
- 불편: 감으로 설명하는 수정 제안이 설득력이 약함
- 가치: 화면·행동 근거가 붙은 리포트 내보내기(Markdown·PDF)

**S16 사용 시나리오: 하루 안에 한 바퀴**
- 화면 연결(5분) → 대상 설명·패널 선택(5분) → 30명 실행 → 리포트 확인 → 이유 궁금한 사람과 인터뷰 → 수정 → 2회차 비교 (앱 화면 캡처 5장)

## 3. 시장성 (8장)

> 시장 숫자는 조사 업체마다 범위 정의가 달라 편차가 크다. 단일 숫자로 단정하지 않고 범위로 제시한다.

**S17 시장 정의**
- 사용성 테스트 소프트웨어 ∩ UX 리서치 도구 ∩ AI 합성 사용자(synthetic users). 벤 다이어그램 한 장

**S18 시장 규모 (범위)** 🔎
- 사용성 테스트 소프트웨어, 2025년 약 4.4억~12억 달러 / 연평균 성장률 6.9~14.8%
  - 보수: 4.42억 달러(2025) → 6.63억 달러(2032), 6.9% — [Intel Market Research](https://www.intelmarketresearch.com/usability-testing-software-2025-2032-623-4342)
  - 낙관: 12억 달러(2025) → 45억 달러(2034), 14.8% — [Market Intelo](https://marketintelo.com/report/usability-testing-software-market/amp)
  - UX 리서치 소프트웨어: 약 4.75억 달러(2025), 10.5% — [Ken Research](https://www.kenresearch.com/industry-reports/global-user-experience-research-software-market)
- 계획 범위: 연 7~15%. 유료 보고서 요약 기반이라 원자료는 확인하지 못했다

**S19 왜 지금인가**
- AI 에이전트가 화면을 직접 조작하는 기술이 가능해졌다 (UXAgent 등 연구 🔎 [arXiv](https://arxiv.org/abs/2504.09407))
- 디자이너가 아닌 사람이 화면을 만드는 비중 증가(Figma 사용자 2/3) 🔎
- 합성 사용자 도구가 새 범주로 자리잡는 중 🔎 [시장 지도](https://sourceforge.net/software/synthetic-user-tools)
- 주의: 국내 신규 창업 수는 감소 중이라 "국내 팀 수 증가"에 기대지 않는다 🔎

**S20 경쟁·대체재 포지셔닝 맵**
- 축: 사람 참가자 ↔ 합성 사용자 / 질문형 ↔ 행동 탐색형
- 우리 위치: **합성 사용자 + 행동 탐색 + 한국 데이터**

**S21 경쟁 서비스 비교표**

| 서비스 | 하는 일 | 우리와 차이 |
| --- | --- | --- |
| Versive | 실제 사용자와 AI 페르소나를 한 스터디에서 결합, 피그마 플러그인 ✅ ([`DEVELOPMENT_PLAN.md`](DEVELOPMENT_PLAN.md) 2-1) | 혼합 구조는 우리가 발명한 것이 아님 |
| UserTesting | 사람 참가자 중심, 피그마 플러그인으로 테스트 스크립트 자동 생성 ✅ | 사람 모집 비용 |
| 인텔리시아(국내) | 합성 소비자에게 설문·인터뷰, 소비재 대기업 중심 ✅ | 화면 조작이 아니라 질의응답 |
| Synthetic Users | 합성 응답자 인터뷰·개념 테스트, URL·스크린샷 태스크 세션, 응답자당 $2~27 🔎 [출처](https://getversive.com/help/synthetic-users-alternatives) | 한국 데이터가 아님 |
| Maze·Lyssna | 사람 참가자 테스트, 월 $99~165 수준 🔎 [G2](https://www.g2.com/products/usabilityhub/pricing) | 사람 모집 필요 |
| Uxia·Brox.ai | 합성 테스터가 UX 흐름을 점검한다고 설명 🔎 | 독립 검증 자료를 찾지 못함 |

- 주의: 비교 글 다수가 경쟁사 블로그라 중립적이지 않다

**S22 우리의 차별점 (과장하지 않기)**
- ① 한국 인구통계·미디어 이용 자료 기반 페르소나 400명 ✅📏
- ② 실제 브라우저 탐색과 화면·행동 근거 저장 ✅
- ③ 같은 페르소나와의 1대1 인터뷰로 이어짐 ✅ (소량 실제 검증 🔶)
- ④ 하나의 탐색 결과를 7개 기준과 페르소나 말투 의견으로 평가 🔶 (백엔드 구현·테스트 통과, 화면 표시와 실제 LLM 실측은 다음 단계)
- ⑤ AI와 실제 사용자를 대조해 오차를 붙이는 설계 ⬜ (계획)
- 문서의 원칙: "혼합 방식 자체는 차별점이 아니다" ✅ ([`DEVELOPMENT_PLAN.md`](DEVELOPMENT_PLAN.md) 2-2)

**S23 합성 사용자에 대한 회의론과 우리의 입장** 🔎
- 연구 근거(긍정): 스탠퍼드 연구에서 인터뷰 기반 에이전트는 1,052명의 설문 답을 본인이 2주 뒤 다시 답한 일관성의 85% 수준으로 재현했다(원점수로는 에이전트 정확도 68.85% ÷ 본인 일관성 81.25%) [arXiv](https://arxiv.org/abs/2411.10109), [HAI](https://hai.stanford.edu/policy/simulating-human-behavior-with-ai-agents)
- 연구 근거(주의): UXAgent 연구에서 UX 연구자 16명은 20개 에이전트의 사용성 테스트 데이터가 스터디 설계 반복에는 유용하지만 사람 행동으로는 완전히 현실적이지 않고 편향 우려가 있다고 평가 [arXiv](https://arxiv.org/abs/2504.09407)
- 현업의 비판: SAP 리서치 리더는 합성 사용자만으로 UX 리서치를 성공적으로 하기는 불가능하다고 말했고, ACM Interactions(2026-01)는 합성 페르소나를 "범주 오류"로 지적 [uxdesign.cc 글](https://uxdesign.cc/are-synthetic-users-really-the-future-of-ux-research-fd76fcb479ec)
- **우리의 입장: 대체가 아니라 사전 점검(스크리닝).** 실제 사용자 조사 전에 구조적 문제를 먼저 거른다. 같은 이유로 "의향"이 아니라 "화면 행동"만 다룬다

- 페르소나 1명(최대 6턴 + 평가 1회) ≈ 6 × $0.0014 + $0.002 ≈ **$0.01**
- 30명 실행 ≈ $0.31, 100명 실행 ≈ $1.0 (±2배 오차 가능) → 30명 실행당 약 430원
- 고정비: 서버·DB. 무료 플랜(Render·Neon 등)으로 시작 가능하나 브라우저 실행 메모리 한계 검증 필요 ⬜

- Plus(14,900원) 한 명이 크레딧 100 페르소나-실행을 모두 쓰면 원가 약 $1 ≈ 1,400원 → 원가율 약 9%
